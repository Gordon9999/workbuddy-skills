# workbuddy-skills

个人定制 WorkBuddy skills 备份仓库。换机 / OS 重装后恢复：

```bash
git clone git@github.com:Gordon9999/workbuddy-skills.git
cp -R workbuddy-skills/skills/* ~/.workbuddy/skills/
```

## 收录技能（2026-09-11 全量重建）

| 技能 | 用途 |
|---|---|
| business-trip-planner | 出差行程三件套（行程 / 订单 / 清单）HTML |
| finance-news-daily | 每日四主题财经新闻推文流 |
| insightview | 主题阅读与综合报告生成（YouTube / 深度文章 / Twitter） |
| mubu-export | 导出幕布桌面端全部文档为 Markdown |
| my-writer | 个人书写风格格式化（mywriter 排版规范） |
| quote-clipper | 摘句本（一句话收藏 + 静态快照 HTML） |

更新方式：改动 `~/.workbuddy/skills/` 后，把对应目录覆盖到本仓库 `skills/` 并 push。
